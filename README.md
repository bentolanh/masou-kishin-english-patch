# Masou Kishin English Patch

English fan translations of the PSP *Super Robot Taisen OG Saga: Masou Kishin* games.

| Game | Disc ID | Status |
|---|---|---|
| **Masou Kishin – The Lord of Elemental** (魔装機神 THE LORD OF ELEMENTAL) | NPJH50804 | **Complete — [download v1.31](../../releases/latest)** |
| **Masou Kishin II – Revelation of Evil God** (魔装機神II REVELATION OF EVIL GOD) | — | In progress, no patch yet |

The patches are applied to **your own copy** of the game. No game files are distributed
here, and none will be provided on request.

## The Lord of Elemental

Everything you read in the game is in English: the whole story script, every battle
quote, menus, unit and character names, the in-game glossary, chapter titles, music
titles and the staff roll. Speaker names are coloured so they stand apart from the line
being spoken, and choice prompts are laid out as separate options.

Full details, the ROM you need, and installation steps: **[lord-of-elemental/](lord-of-elemental/)**

### Quick start

1. Get an ISO of your own copy that matches this exactly:

   | | |
   |---|---|
   | Disc ID | `NPJH50804` (Japan, PSN release) |
   | Size | 537,985,024 bytes |
   | CRC32 | `66b342f4` |
   | MD5 | `a2e4ee7060a73fb74c01bb95f00f72aa` |
   | SHA-1 | `5ad027ea4d605b04b8201f6b7319d43f75b087f8` |

2. Apply `masou-kishin-lord-of-elemental-english-v1.31.xdelta` from the
   [latest release](../../releases/latest) with any xdelta patcher.
3. *Optional, PPSSPP only:* install the texture pack from the same release to translate
   the Japanese that the game draws as pictures rather than text.

## Revelation of Evil God

Work has started: the script is dumped and the names are being settled against the first
game's English so the two read as one series. There is no patch to download yet. Watch
the repository for a release.

## Credits

Translated with machine assistance (Claude), then reviewed scene by scene against the
Japanese so each line is read beside the lines around it. Names follow the SNES fan
translation and the Super Robot Wars wiki where those were already settled.

Found a line that reads wrong? Open an issue and quote the English text — every line in
the patch can be found from its wording.
